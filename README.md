# Student Grades Calculator

A simple student grade calculator built with Python and Streamlit.

## Features

- Enter a student's name
- Enter grades in Math, English, and Science
- Calculate the average grade
- Assign a letter grade (A, B, C, or F)
- Display the student's result and pass/fail status
- Visualize grades with a bar chart

## Technologies Used

- Python
- Streamlit
- Pandas

## Installation

1. Install Python.
2. Install the required packages:

   pip install -r requirements.txt
   

## Run the Application

Run the following command from the project directory:

   python -m streamlit run student_grades_app.py


## Project Purpose

This project was created to practise Python programming, user input handling, basic calculations, and data visualization.
